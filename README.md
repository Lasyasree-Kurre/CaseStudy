# 🏧 ATM Transaction System in C

A simple menu-driven C program that simulates basic ATM operations using the `switch` statement.

## ✨ Features

- 💰 **Balance Inquiry** — Displays the current account balance.
- 💸 **Cash Withdrawal** — Withdraws money if sufficient balance is available.
- 💵 **Cash Deposit** — Deposits money and updates the balance.
- ⚠️ **Error Handling** — Displays messages for insufficient balance and invalid options.

## 🛠️ Concepts Used

- `printf()` and `scanf()`
- `switch-case` statements
- `if-else` statements
- Arithmetic operators
- Variables and user input
